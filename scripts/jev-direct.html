Jev 入力実験

ゲームとは独立したローカル画面です。送信すると、この PC から TypeSafe API に直接リクエストします。Cloudflare は通りません。

① 入力を作る

候補は ata_things.json、お題は ata_descriptions.json、指示文は jev_prompts.json から読みます。「元に戻す」は同じ候補を再取得します。

下の JSON は直接編集できます。細かい入力形式もここで試せます。

② 直接送信

キーはブラウザに保存せず、localhost のサーバー経由で TypeSafe に送ります。

実送信は TypeSafe の利用料金が発生する可能性があります。自動送信はしません。サーバー起動中は最大30回までです。

③ 応答を見る

送信すると、HTTP 状態・処理時間・Jev の応答を表示します。
